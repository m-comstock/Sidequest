# Sidequest

My personal design system: a late-night palette lit by one golden-hour color, Sora and Inter type, pill buttons and a color for each area of life.

- **Read it:** [DESIGN.md](DESIGN.md) is the complete reference, written for people and AI assistants.
- **See it:** open [assets/starter.html](assets/starter.html) locally for every component in Night and Day.
- **Use it as a skill:** this folder follows the [Agent Skills](https://agentskills.io) format (`SKILL.md` at the root), so Claude, ChatGPT, Hermes Agent and other compatible tools can install it directly.
